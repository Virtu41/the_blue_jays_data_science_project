# the_blue_jays_data_science_project
The Toronto Blue Jays postseason pitching analysis
This project analyzes Toronto Blue Jays pitching performance throughout the 2025 MLB postseason.

Our research question is:

What pitch should be thrown on the first pitch of an at-bat, by any given pitcher, and where in the strike zone should it be located?

Project Structure

 – Pitcher performance and postseason progression analysis.

 – Pitch-type effectiveness and pitch-location analysis.

– First-pitch ball versus strike analysis.

 – Fastball velocity progression throughout games.

 – Repeated batter encounters and pitcher performance.

Files

This repository contains the group's Python scripts, Jupyter notebooks, HTML exports, and relevant analysis outputs.

Research Objective

The goal is to use our analysis to identify patterns in pitching effectiveness and develop evidence-based recommendations for first-pitch selection and location.
